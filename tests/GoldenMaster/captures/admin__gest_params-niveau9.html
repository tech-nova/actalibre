Paramétrage du site "Expoactes"

Paramètres : Affichage | Géoloc | Mail | Protection | Recherche | Système | Utilisateurs || Backup

Affichage

Nom du site principal (?)
SITENAME : Nom du site utiliés dans le cartouche de tête et dans les mails automatiques. :
URL du site principal (?)
SITE_URL : URL relative ou absolue du site web principal (utilisée pour créer un lien de retour vers le site principal). :
Eléments affichés par page (?)
MAX_PAGE : Nombre références d'actes affichés par pages dans les recherches :
Eléments par page (mode administration) (?)
MAX_PAGE_ADM : Nombre références d'actes affichés par pages dans les recherches en mode administration :
Basculement en mode alphabétique (?)
MAX_PATR : Nombre de patronymes à partir duquel on passe en mode de regroupement alphabétique ABC..Z :
Mode alphabétique (mode administration) (?)
MAX_PATR_ADM : Nombre de patronymes à partir duquel on passe en mode de regroupement alphabétique ABC..Z (en mode administration) :
Accueil : affichage des dates min. et max. (?)
SHOW_DATES : Détermine si les dates minimales et maximales des actes d'une commune sont affichées dans la page d'accueil d'Expoactes. :
Accueil : lien vers la distribution des années (?)
SHOW_DISTRIBUTION : Détermine si l'icône faisant le lien vers les statistiques des actes par années est présent dans le tableau public. NB : L'affichage de lien nécessite aussi que le paramètre précédent soit activé. :
Accueil : afficher tous les types d'actes (?)
SHOW_ALLTYPES : Détermine si la page d'accueil affiche le tableau résumé des quatre types d'actes (par défaut) ou d'un seul. :
Tables : affichages des années seulement (?)
ANNEE_TABLE : L'affichage des tables d'actes présente en principe la date complète des actes. Si vous souhaitez limiter cet affichage à l'année seulement pour les visiteurs non connectés ou les non déposants (niveau=4), il suffit de sélectionner la valeur appropriée. :
Actes : images seulement si login (?)
JPG_SI_LOGIN : Lorsque cette case est cochée, le lien vers les images d'actes (zone "Libre") n'apparait que lorsque le visiteur est connecté; dans le cas contraire le texte "image privée" est affiché. :
Texte d'avertissement (?)
AVERTISMT : Texte facultatif à afficher en tête de la première page au dessus de l'inventaire des communes. :
Pied de page (?)
PIED_PAGE : Texte libre du pied de page : peut contenir un texte ou un script javascript (pour un compteur de visiteurs par exemple). :
Zone de pub sous le menu (?)
PUB_ZONE_MENU : Il est possible de faire afficher sous le menu un texte quelconque tels qu'une publicité pour vos activités. Il peut aussi être utilisé pour afficher un cadre de publicités type "Google Adsens". Cette zone doit être complétée par du HTML valide. Le style .pub_menu peut être utilement créé dans la CSS. :
Message acceptation des cookies (?)
COOKIE_MESSAGE : Ce message, affiché tous les ans, annonce l'utilisation des cookies sur le site. Vous pouvez personnaliser le message en fonction des services activés (google analytics, publicité, ...) :
URL d'une page sur les cookies (?)
COOKIE_URL_INFO : Cette page permet au visiteur d'en savoir plus sur les cookies. Il peut s'agir d'une page interne au site ou externe. :
Style du message cookies (?)
COOKIE_STYLE : Position du bandeau de consentement : en haut, en bas ou flottant. La variante claire ou foncée n'est plus appliquée. :
