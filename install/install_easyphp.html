Installer ActaLibre sur un Apache local

Cette aide issue d’ExpoActes a été adaptée pour ActaLibre. Utiliser un environnement Apache avec PHP ≥ 8.3 et les extensions figurant dans composer.json, notamment mysqli et mysqlnd. Les autres serveurs ne sont pas pris en charge en 1.0.

Préparer MySQL

Créer une base vide et un utilisateur ayant les droits sur cette base. Aucun jeu de données ExpoActes n’est nécessaire.

Placer le site et l’installer

Extraire l’archive ActaLibre entière dans un dossier servi par Apache, puis ouvrir install.php. Indiquer son adresse complète, sous-dossier compris. Le fichier de connexion reste dans _config/, les journaux et sauvegardes sont dans tmp/.

Une installation existante se met à jour par update.php, après sauvegarde. La migration ExpoActes accepte uniquement 3.2.4. Après une interruption, reprendre le formulaire ; un administrateur déjà créé doit s’authentifier.

Contrôler ensuite les protections et les chemins inconnus dans l’administration. Un avertissement ne déplace aucun fichier et ne bloque pas les écritures SQL. Voir INSTALL.md et la configuration du site.

Liens historiques : EasyPHP et WampServer. Vérifier leurs versions de PHP et d’Apache avant utilisation.
