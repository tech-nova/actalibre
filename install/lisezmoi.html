Installation d’ActaLibre

ActaLibre conserve l’origine et les attributions d’ExpoActes. Pour ses instructions actuelles, consulter INSTALL.md : Apache et PHP ≥ 8.3, extensions indiquées dans composer.json.

Préparer les fichiers

Extraire l’archive ActaLibre complète, y compris ses fichiers cachés, composer.json et inventaire-actalibre.json. Aucun programme d’installation Windows ni Composer n’est requis sur le serveur.

Transférer le site

Transférer les fichiers par FTP dans le dossier choisi. Avant une mise à jour, sauvegarder tous les fichiers et toutes les bases, y compris celle des comptes. Seule la migration depuis ExpoActes 3.2.4 est prise en charge.

Installer ou mettre à jour

Sur une base vierge, ouvrir install.php et saisir l’adresse complète du site, les accès MySQL et le premier administrateur. Les données initiales sont livrées ; aucune donnée ExpoActes n’est nécessaire. Pour une migration ou une base rattachée, ouvrir update.php avec un compte de niveau 9. Les formulaires permettent de reprendre une interruption.

La configuration reste dans _config/. Les nouveaux journaux et sauvegardes sont dans tmp/. La migration archive les anciens dossiers _logs et _backup en bloc dans tmp/archive/YYMMDDHHMMSS/, sans bloquer SQL si ce renommage échoue.

Après installation ou mise à jour, vérifier le contrôle des protections et les fichiers non reconnus. Un contrôle non vérifié affiche un avertissement et se relance depuis l’administration. Les fichiers inconnus sont seulement signalés : les vérifier et retirer manuellement par FTP. Les autres serveurs qu’Apache ne sont pas pris en charge en 1.0.

Pour personnaliser le site : paramètres. Pour un diagnostic : codes d’erreur.
