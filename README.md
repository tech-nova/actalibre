# ActaLibre
ActaLibre est un fork d'ExpoActes 3.2.4, une solution web PHP MySQL OpenSource qui permet de regrouper, de gérer et de diffuser sur internet des actes généalogiques.

Il renforce la sécurité, porte le code vers PHP 8.4 et le refactorise progressivement, sans changer l'interface. Il n'est pas maintenu par l'équipe d'ExpoActes.

Dernières versions :
- ActaLibre 1.1.0
- Version d'origine : ExpoActes version 3.2.4 (février 2022)

## Installation

Voir [INSTALL.md](INSTALL.md). Installation sur base vierge ou migration depuis ExpoActes **3.2.4 uniquement** ; aucune donnée ExpoActes n’est nécessaire à une installation neuve. La première version prend en charge Apache.

## Environnement
    * PHP 8.3 ou plus récent (tests faits en PHP 8.3 et 8.4)
    * MySQL (tests faits en MySQL 8.0)
    * Pilote mysqlnd, pour les pages migrées vers les requêtes préparées

## Documentation
Voir [INSTALL.md](INSTALL.md) pour les prérequis, les reprises, le stockage privé sous `tmp/`, le contrôle des protections et le retrait manuel des fichiers non reconnus. La configuration reste dans `_config/`.

Pour contribuer au code et lancer les tests, voir [CONTRIBUTING.md](CONTRIBUTING.md).
